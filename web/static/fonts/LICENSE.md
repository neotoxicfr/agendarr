# TwemojiCountryFlags.woff2

From [country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill)
0.1.10 (MIT, Copyright (c) 2022 TalkJS): a subset of
[Twemoji Mozilla](https://github.com/mozilla/twemoji-colr) holding only the
country flags, so that Windows, which has no flag emoji, shows them too.

The flag artwork is from [Twemoji](https://github.com/twitter/twemoji),

[CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/).
